# Team C_Hands-InvoiceQuick

InvoiceQuick is a simple invoice maker that exports to PDF. Target price: $4.99.

## Features
- Invoice number, issue and due dates, from / bill-to blocks
- Line items with quantity x rate, auto subtotal, tax % and total, custom currency symbol
- Notes for payment terms
- Export to PDF via the browser print dialog (clean print layout, controls hidden)
- Auto-saves in your browser (localStorage); no account or server

## Run
Open `index.html` in any modern browser, or `python3 -m http.server 8000` and visit http://localhost:8000.
